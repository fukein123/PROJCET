# 结构和配置文档

更新时间：2026-03-13

## 1. 项目目录

```text
zero/
├─ Frontend/                    # 前端（Vue 3 + TS + Vite）
├─ backend/                     # 后端（Spring Boot）
├─ file/                        # 项目文档
├─ skills/                      # 项目内核心 skill
├─ .spec-workflow/              # 规格工作流文档
├─ README.md
└─ .gitignore
```

## 2. 前端结构（`Frontend/src`）

```text
src/
├─ api/                         # 接口封装
├─ assets/styles/               # 主题样式
├─ components/                  # 复用组件
├─ composables/                 # 复用逻辑（分页、导航等）
├─ layouts/                     # 主布局
├─ router/                      # 路由与守卫
├─ stores/                      # Pinia 状态
├─ utils/                       # 展示、校验、上传等工具函数
└─ views/                       # 页面（activity/audit/auth/content/dashboard/portal/settings/user/volunteer）
```

## 3. 后端结构（`backend/src/main/java/com/community`）

```text
common/
├─ config/                      # 安全、跨域、OpenAPI、MyBatis
├─ constant/
├─ dto/
├─ entity/
├─ exception/
├─ util/
└─ web/                         # ApiResponse / PageResult
modules/
├─ activity/
├─ auth/
├─ common/
├─ content/
├─ dashboard/
├─ schedule/
└─ user/
```

## 4. 环境配置

- JDK：21
- Maven：3.9.13
- MySQL：8.0+
- Node.js：20+
- Nginx：可选，用于生产反向代理

## 5. 关键配置文件

- 后端
  - `backend/src/main/resources/application.yml`
  - `backend/src/main/resources/application-dev.yml`
  - `backend/src/main/resources/application-prod.yml`
- 前端
  - 当前未提交 `.env` 文件，默认通过 `VITE_API_BASE_URL` 读取后端地址
  - 开发时默认回落到 `http://localhost:8080`
