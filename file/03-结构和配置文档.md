# 结构和配置文档

更新时间：2026-03-14

## 1. 顶层结构

```text
zero/
├─ Frontend/                    # 前端应用
├─ backend/                     # 后端服务
├─ file/                        # 项目文档与阶段记录
├─ scripts/                     # 自动化脚本
├─ skills/                      # 仓库内最小 skill 快照
├─ tmp/                         # 临时验证产物
└─ README.md
```

## 2. 前端边界

前端根目录：`Frontend/src`

- `api/`：唯一的后端 REST 调用封装层
- `components/`：可复用组件
- `composables/`：复用逻辑
- `constants/`：路由与状态常量
- `layouts/`：后台主布局与门户自助布局
- `router/`：路由与权限守卫
- `stores/`：Pinia 状态
- `utils/`：展示、上传、确认动作等工具
- `views/`：按业务模块划分页面

前端边界要求：

- 页面不直接拼接后端地址，统一走 `api/*`
- 管理端走 `/admin/*`
- 门户与志愿者自助走 `/portal/*`
- 旧 `/volunteer/*` 仅保留过渡跳转

## 3. 后端边界

后端根包：`backend/src/main/java/com/community`

- `common/`：安全、异常、统一返回、基础工具
- `modules/activity/`：活动、报名、打卡
- `modules/content/`：动态、公告、帖子、评论、商城、订单、轮播图、收藏
- `modules/dashboard/`：后台统计与看板
- `modules/user/`：用户、认证、积分
- `modules/audit/`：管理员操作审计

后端边界要求：

- 控制器只承接接口协议，不堆业务细节
- 核心状态流转和校验必须落在 service 层
- 管理员操作留痕统一进入审计日志

## 4. 数据库边界

数据库相关目录：`backend/src/main/resources/db`

- `migration/`：Flyway 迁移脚本与迁移说明
- `init-database.sql`：仅用于数据库/账号/授权的手工引导
- `schema.sql`、`data.sql`：退役占位说明，不再参与运行期初始化

数据库边界要求：

- 所有结构变更必须新增 `V*.sql`
- 参考数据更新走 `R*.sql`
- 不回写已落地的历史迁移语义
