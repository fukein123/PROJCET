# 结构和配置文档

```text

├─ admin/                       # Vue 前端
├─ backend/                     # Spring Boot 后端
├─ skills/                      # 项目内 skills

└─ README.md
```

## 3. 后端结构（`backend/src/main/java/com/community`）

```text
common/
├─ config/
├─ constant/
├─ entity/
├─ exception/
├─ util/
└─ web/
modules/
├─ auth/
├─ user/
├─ activity/
├─ content/
├─ dashboard/

```

其中 `dashboard` 模块新增周统计能力，包含周维度志愿者服务排名查询与重建逻辑。
