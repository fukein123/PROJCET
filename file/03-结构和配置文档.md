# 结构和配置文档

更新时间：2026-03-12

## 1. 项目目录

```text
zero/
├─ admin/                       # 前端（Vue 3 + TS + Vite）
├─ backend/                     # 后端（Spring Boot）
├─ file/                        # 项目文档
├─ skills/                      # 本地技能库
├─ README.md
└─ .gitignore
```

## 2. 前端结构（`admin/src`）

```text
src/
├─ api/                         # 接口封装
├─ assets/styles/               # 主题样式
├─ components/                  # 复用组件
├─ composables/                 # 复用逻辑（含门户导航守卫）
├─ layouts/                     # 主布局
├─ router/                      # 路由与守卫
├─ stores/                      # Pinia 状态
├─ utils/                       # 工具函数
└─ views/                       # 页面（auth/portal/admin/volunteer）
```

## 3. 后端结构（`backend/src/main/java/com/community`）

```text
common/
├─ config/                      # 安全、跨域、OpenAPI、MyBatis
├─ constant/
├─ entity/
├─ exception/
├─ util/
└─ web/                         # ApiResponse / PageResult
modules/
├─ auth/
├─ user/
├─ activity/
├─ content/
├─ dashboard/
└─ schedule/
```

## 4. 环境配置

- JDK：21
- Maven：3.9.13（建议本地仓库 `E:/mvn_repo`）
- MySQL：8.0+，数据库 `CVS`
- Node.js：20+
- Nginx：建议监听端口 `70`，反代 `/api` 到后端 `8080`

## 5. 配置文件

- 后端：
  - `backend/src/main/resources/application.yml`
  - `backend/src/main/resources/application-dev.yml`
  - `backend/src/main/resources/application-prod.yml`
- 前端：
  - `admin/.env.development`
  - `admin/.env.production`
