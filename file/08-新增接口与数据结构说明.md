# 新增接口与数据结构说明

更新时间：2026-03-13

## 1. 后端新增/扩展接口

### 1.1 通用上传

- `POST /api/common/upload`
  - 入参：`multipart/form-data`，字段 `file`
  - 返回：`{ url, name, size, originalName }`
  - 用途：注册头像、活动封面、动态配图上传。

### 1.2 活动模块（管理员增强）

- `DELETE /api/activity/categories/{id}`
- `POST /api/activity/categories/batch-delete`（`{ ids: number[] }`）
- `DELETE /api/activity/{id}`
- `POST /api/activity/batch-delete`（`{ ids: number[] }`）
- `POST /api/activity/batch-archive`（`{ ids: number[] }`）
- `POST /api/activity/batch-restore`（`{ ids: number[] }`）
- `GET /api/activity/page`
  - 新增查询参数：`includeArchived`
  - 用途：管理员治理页显式查看 `ARCHIVED` 活动；门户端/志愿者端默认不透出

### 1.3 内容模块（管理员增强）

- 动态：
  - `DELETE /api/content/dynamics/{id}`
  - `POST /api/content/dynamics/batch-delete`
  - `POST /api/content/dynamics/batch-archive`
  - `POST /api/content/dynamics/batch-restore`
- 公告：
  - `DELETE /api/content/notices/{id}`
  - `POST /api/content/notices/batch-delete`
  - `POST /api/content/notices/batch-archive`
  - `POST /api/content/notices/batch-restore`
- 帖子：
  - `DELETE /api/content/forum/posts/{id}`
  - `POST /api/content/forum/posts/batch-delete`
- 评论：
  - `DELETE /api/content/comments/{id}`
  - `POST /api/content/comments/batch-delete`

### 1.4 收藏模块（志愿者 CRUD）

- `GET /api/content/favorites/page`
- `POST /api/content/favorites`
- `PUT /api/content/favorites/{id}`
- `DELETE /api/content/favorites/id/{id}`
- `POST /api/content/favorites/batch-delete`

> 保留兼容接口：`POST/DELETE /api/content/favorites/{activityId}`。

### 1.5 打卡记录增强

- `GET /api/activity/sign/my-records`
  - 返回结构从基础记录扩展为 `CheckRecordView`，新增字段：
    - `activityTitle`
    - `activityAddress`
    - `activityStartTime`
    - `activityEndTime`
    - `serviceMinutes`

### 1.6 用户管理（管理员）

- `POST /api/users`
  - 新增志愿者账号（含初始密码、姓名、手机号、邮箱等）
- `DELETE /api/users/{id}`
  - 删除志愿者账号
- `POST /api/users/batch-delete`
  - 批量删除志愿者账号

### 1.7 活动报名与评论增强

- `GET /api/activity/applications/page`
- `GET /api/activity/applications/my`
  - 返回由 `ActivityApplication` 升级为 `ActivityApplicationView`，包含：
    - `activityTitle`
    - `username`
    - `realName`
- `GET /api/content/comments/page`
  - 新增参数：`targetId`
  - 用于按具体活动分页查询评价列表（`targetType=ACTIVITY`）

## 2. 数据结构变化

### 2.1 `activity`

新增字段：

- `cover_image VARCHAR(255)`：活动封面图。
- `volunteer_quota INT`：志愿者人数上限。
- `content VARCHAR(500)`：活动内容摘要。
- `status ENUM(..., 'ARCHIVED')`：新增后台治理归档状态，区别于自然结束 `ENDED`。

删除字段：

- `latitude`
- `longitude`

### 2.2 `info_dynamic`

新增字段：

- `image_url VARCHAR(255)`：动态配图。

### 2.3 `favorite_activity`

新增字段：

- `activity_title VARCHAR(255)`：收藏创建时的活动标题快照。
- `activity_address VARCHAR(255)`：收藏创建时的活动地点快照。
- `activity_start_time DATETIME`：收藏创建时的活动开始时间快照。
- `activity_end_time DATETIME`：收藏创建时的活动结束时间快照。
- `note VARCHAR(255)`：收藏备注。
- `tag VARCHAR(64)`：收藏标签。
- `priority INT`：优先级（0-5）。

## 3. 去积分化说明

- 管理端统计项由 `orderCount` 替换为 `commentCount`。
- 门户导航移除积分入口。
- 种子数据移除积分导向文案。

## 4. 前端对应改造点

- `src/api/common.ts`：新增上传 API。
- `src/api/activity.ts`：活动字段扩展（`content/volunteerQuota`）、报名视图增强、去经纬度打卡入参；新增 `includeArchived`、批量归档、批量恢复接口。
- `src/api/content.ts`：评论分页支持 `targetId`，活动评价可按活动维度查询；收藏模型新增活动标题、地点、时间快照字段；动态/公告新增批量归档、批量恢复接口。
- `src/api/user.ts`：管理员新增志愿者、删除、批量删除接口。
