# 新增接口与数据结构说明

更新时间：2026-03-12

## 1. 后端新增/扩展接口

### 1.1 通用上传

- `POST /api/common/upload`
  - 入参：`multipart/form-data`，字段 `file`
  - 返回：`{ url, name, size, originalName }`
  - 用途：注册头像、活动封面、动态配图上传。

### 1.2 活动模块（管理员增强）

- `DELETE /api/activity/categories/{id}`
- `POST /api/activity/categories/batch-delete`（`{ ids: number[] }`）
- `DELETE /api/activity/{id}`
- `POST /api/activity/batch-delete`（`{ ids: number[] }`）

### 1.3 内容模块（管理员增强）

- 动态：
  - `DELETE /api/content/dynamics/{id}`
  - `POST /api/content/dynamics/batch-delete`
- 公告：
  - `DELETE /api/content/notices/{id}`
  - `POST /api/content/notices/batch-delete`
- 帖子：
  - `DELETE /api/content/forum/posts/{id}`
  - `POST /api/content/forum/posts/batch-delete`
- 评论：
  - `DELETE /api/content/comments/{id}`
  - `POST /api/content/comments/batch-delete`

### 1.4 收藏模块（志愿者 CRUD）

- `GET /api/content/favorites/page`
- `POST /api/content/favorites`
- `PUT /api/content/favorites/{id}`
- `DELETE /api/content/favorites/id/{id}`
- `POST /api/content/favorites/batch-delete`

> 保留兼容接口：`POST/DELETE /api/content/favorites/{activityId}`。

### 1.5 打卡记录增强

- `GET /api/activity/sign/my-records`
  - 返回结构从基础记录扩展为 `CheckRecordView`，新增字段：
    - `activityTitle`
    - `activityAddress`
    - `activityStartTime`
    - `activityEndTime`
    - `signInDistance`
    - `signOutDistance`
    - `serviceMinutes`

## 2. 数据结构变化

### 2.1 `activity`

新增字段：

- `cover_image VARCHAR(255)`：活动封面图。

### 2.2 `info_dynamic`

新增字段：

- `image_url VARCHAR(255)`：动态配图。

### 2.3 `favorite_activity`

新增字段：

- `note VARCHAR(255)`：收藏备注。
- `tag VARCHAR(64)`：收藏标签。
- `priority INT`：优先级（0-5）。

## 3. 去积分化说明

- 管理端统计项由 `orderCount` 替换为 `commentCount`。
- 门户导航移除积分入口。
- 种子数据移除积分导向文案。

## 4. 前端对应改造点

- `src/api/common.ts`：新增上传 API。
- `src/api/activity.ts`：活动/分类删除与批量删除、打卡结构扩展。
- `src/api/content.ts`：动态/公告/帖子/评论批量删除与收藏 CRUD。
