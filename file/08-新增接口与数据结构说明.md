# 新增接口与数据结构说明

更新时间：2026-03-11

## 1. 新增数据表

### 1.1 `volunteer_weekly_stats`

用途：存储周维度志愿者服务统计与排名结果（用于管理端统计页和定时任务产出）。

关键字段：

- `week_start`：周起始日期（周一）
- `user_id` / `username` / `real_name`：志愿者标识
- `completed_count`：本周完成场次（按签退统计）
- `sign_in_count` / `sign_out_count`：签到/签退次数
- `service_minutes`：服务总分钟数
- `rank_no`：排名
- `generated_time`：本批统计生成时间

约束：

- `UNIQUE KEY uk_week_user (week_start, user_id)`

## 2. 新增接口

### 2.1 查询周排名

- 路径：`GET /api/dashboard/weekly-ranking`
- 权限：`ADMIN` / `VOLUNTEER`
- 参数：
  - `weekStart`（可选，`YYYY-MM-DD`，传入周内任意日期，后端归一为周一）
  - `size`（可选，默认 `20`）
- 返回：周区间、生成时间、记录总数、排名记录列表

### 2.2 重建周排名

- 路径：`POST /api/dashboard/weekly-ranking/rebuild`
- 权限：`ADMIN`
- 参数：
  - `weekStart`（可选，不传则默认重建上周）
- 返回：重建行数提示

## 3. 已有接口行为增强

### 3.1 用户管理接口

- 接口：`PUT /api/users/{id}`
- 增强点：支持维护 `certified` 字段（`0/1`）。

### 3.2 论坛帖子分页接口

- 接口：`GET /api/content/forum/posts/page`
- 增强点：
  - 非管理员默认只返回 `APPROVED` 帖子。
  - 志愿者仅在 `onlyMine=true` 时可查看本人待审/拒绝帖子。

### 3.3 兑换订单创建接口

- 接口：`POST /api/content/orders`
- 增强点：
  - 非管理员创建订单时，`user_id` 强制使用当前登录用户，防止越权代下单。

## 4. 定时任务落地

- 任务：每周一 01:00 生成上周周统计
- 入口：`ActivityScheduleTask#weeklyVolunteerRankingJob`
