# 架构与模块

## 角色

- **管理员**：系统与内容管理、活动发布与审核、统计看板
- **志愿者**：注册登录、活动报名与打卡、帖子发布、评论与收藏、认证信息

## 前端（`admin/`）

统一设计风格：简洁大气、组件规范一致、页面布局统一（顶部导航/侧边栏/内容区）。

建议模块（按路由/页面组织）：

- `dashboard/`：统计看板（折线/柱状/饼图）
- `activity/`：活动分类、活动管理、报名审核、打卡记录
- `content/`：信息动态、公告、轮播图
- `forum/`：帖子分类、帖子审核、评论
- `order/`：兑换订单
- `user/`：管理员/志愿者信息、个人中心、修改密码、认证信息

## 后端（`backend/`）

分层与领域拆分：

- `common/`：返回体、异常、常量、工具、配置（CORS/OpenAPI/Security/JWT）
- `modules/`：
  - `user/`：用户与认证信息
  - `activity/`：活动、分类、报名审核、打卡
  - `content/`：信息动态、公告、轮播图
  - `forum/`：帖子、分类、评论、收藏
  - `order/`：兑换订单、积分流水

## 鉴权与权限

- 登录成功返回 JWT
- Spring Security 统一拦截，解析 JWT 得到用户身份与角色
- 管理员接口按 `ROLE_ADMIN` / `ROLE_COMMUNITY_ADMIN` 控制
- 志愿者接口按 `ROLE_VOLUNTEER` 控制
