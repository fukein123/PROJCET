# 接口文档

更新时间：2026-03-12

Base URL：`http://localhost:8080`

统一响应结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

OpenAPI：`/swagger-ui.html`

## 1. 认证接口

- `POST /api/auth/login`
- `POST /api/auth/register`

说明：`/api/auth/login` 支持 `role` 字段（`ADMIN` / `VOLUNTEER`），后端会校验账号角色与登录入口是否一致。

## 2. 用户接口

- `GET /api/users/me`
- `PUT /api/users/me`
- `PUT /api/users/password`
- `GET /api/users/page`（管理员）
- `PUT /api/users/{id}`（管理员）

## 3. 活动接口

### 3.1 分类

- `GET /api/activity/categories`
- `POST /api/activity/categories`（管理员）
- `PUT /api/activity/categories/{id}`（管理员）

### 3.2 活动

- `GET /api/activity/page`
- `GET /api/activity/{id}`
- `POST /api/activity`（管理员）
- `PUT /api/activity/{id}`（管理员）

### 3.3 报名与审核

- `POST /api/activity/{activityId}/apply`（志愿者）
- `GET /api/activity/applications/page`（管理员）
- `GET /api/activity/applications/my`（志愿者）
- `PUT /api/activity/applications/{id}/audit`（管理员）

### 3.4 打卡

- `POST /api/activity/sign/in`（志愿者）
- `POST /api/activity/sign/out`（志愿者）
- `GET /api/activity/sign/my-records`（志愿者）

## 4. 内容接口

### 4.1 门户

- `GET /api/content/home`

### 4.2 动态

- `GET /api/content/dynamics/page`
- `POST /api/content/dynamics`（管理员）
- `PUT /api/content/dynamics/{id}`（管理员）

### 4.3 公告

- `GET /api/content/notices/page`
- `POST /api/content/notices`（管理员）
- `PUT /api/content/notices/{id}`（管理员）

### 4.4 论坛

- `GET /api/content/forum/categories`
- `POST /api/content/forum/categories`（管理员）
- `PUT /api/content/forum/categories/{id}`（管理员）
- `GET /api/content/forum/posts/page`
- `POST /api/content/forum/posts/my`（志愿者）
- `PUT /api/content/forum/posts/{id}/audit`（管理员）

### 4.5 评论

- `GET /api/content/comments/page`（公开）
- `POST /api/content/comments`（管理员/志愿者）

### 4.6 收藏与兑换

- `GET /api/content/favorites`（志愿者）
- `POST /api/content/favorites/{activityId}`（志愿者）
- `DELETE /api/content/favorites/{activityId}`（志愿者）
- `GET /api/content/orders/page`（登录用户）
- `POST /api/content/orders`（登录用户）

## 5. 统计接口

- `GET /api/dashboard/admin`（管理员）
- `GET /api/dashboard/weekly-ranking`（管理员/志愿者）
- `POST /api/dashboard/weekly-ranking/rebuild`（管理员）
