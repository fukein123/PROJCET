# 系统设计文档

更新时间：2026-03-12

## 1. 角色模型

### 1.1 管理员（ADMIN）

- 活动与分类管理
- 报名审核
- 资讯/公告/帖子审核
- 用户管理
- 统计看板

### 1.2 志愿者（VOLUNTEER）

- 注册登录与资料维护
- 活动报名、签到签退
- 帖子发布与评论
- 收藏与个人记录

## 2. 核心业务规则

### 2.1 登录规则

- 登录页区分“管理员登录”和“用户登录”入口。
- 后端根据账号角色校验登录入口，防止角色误入。

### 2.2 报名规则

- 门户页面仅展示活动；报名动作要求先登录。
- 管理员账号不可执行志愿者报名。

### 2.3 帖子与评论规则

- 志愿者发帖后进入 `PENDING` 待审核状态。
- 非管理员默认只可见 `APPROVED` 帖子。
- 评论新增需要登录；评论列表可公开展示。

### 2.4 打卡规则

- 签到窗口：活动开始前15分钟至活动开始时刻。
- 签退窗口：活动结束前15分钟之后。
- 采用经纬度距离校验。

## 3. 安全设计

- JWT 无状态认证。
- Spring Security + `@PreAuthorize` 控制权限。
- BCrypt 密码存储。
- 统一异常处理与统一响应模型。

## 4. 体验设计原则

- 门户作为主页面：活动、论坛、公告优先展示。
- 登录/注册页面统一视觉风格，减少留白，增加引导信息。
- 管理员与志愿者工作台显式角色标识，避免混淆。
- 对话框/抽屉统一可滚动，避免编辑页面内容截断。
