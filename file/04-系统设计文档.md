# 系统设计文档

## 1. 角色模型

### 管理员（ADMIN）

- 登录、个人信息、修改密码
- 活动分类/活动管理
- 活动报名审核
- 信息动态、公告、论坛审核
- 用户管理、统计看板

### 志愿者（VOLUNTEER）

- 注册、登录、个人中心、修改密码
- 活动查询与报名
- 报名记录、签到签退、打卡记录
- 发帖、评论、收藏

## 2. 核心业务规则

## 2.1 报名规则

- 志愿者认证通过后才能报名
- 同一用户同一活动只允许一条报名记录
- 管理员可审核通过或拒绝（拒绝需填写理由）

## 2.2 打卡规则

- 签到窗口：`活动开始前15分钟` 到 `活动开始时间`
- 签退窗口：`活动结束前15分钟之后`
- GPS 距离校验：默认 500 米范围
- 同活动同用户只保留一条打卡记录（签到+签退）

## 2.3 帖子审核规则

- 志愿者新增/修改帖子后，状态自动变为 `PENDING`
- 管理员审核通过后进入公开论坛

## 3. 安全设计

- JWT 无状态认证
- Spring Security 鉴权 + `@PreAuthorize` 角色控制
- 密码 BCrypt 存储
- 统一异常处理与错误码
- CORS 统一配置

- `info_dynamic`
- `forum_category`
- `forum_post`
- `comment_info`
- `banner_info`
- `notice_info`
- `exchange_order`
- `favorite_activity`
- `volunteer_weekly_stats`

## 5. 定时任务设计

- 每日 00:00 扫描活动，自动将过期活动标记为 `ENDED`
- 每周一 01:00 生成上周志愿者服务周统计（签到/签退/服务分钟/排名）
