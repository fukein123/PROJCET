# 自动化冒烟脚本说明（登录 / 报名 / 收藏快照 / 评论 / 审核 / 签到签退 / 周统计 / 归档恢复 / 批量删除 / 退出 / 清理校验）

更新时间：2026-03-13

## 1. 脚本位置

- 文件：`Frontend/scripts/smoke-flow.mjs`
- 覆盖流程：
  1. 志愿者登录
  2. 后端 API 预置临时主活动，门户活动页自动报名
  3. 志愿者活动中心对专用临时活动执行收藏
  4. 管理端修改被收藏活动的当前信息，志愿者侧校验“我的收藏”仍显示快照标题、地点与时间
  5. 门户论坛发布测试评论
  6. 管理端审核报名申请
  7. 志愿者端完成签到、签退并校验打卡记录
  8. 管理端重建周统计并校验榜单刷新
  9. 管理端活动管理页执行批量归档、恢复发布
  10. 管理端内容管理页执行动态批量归档、恢复发布
  11. 管理端内容管理页执行公告批量归档、恢复发布
  12. 管理端活动分类页执行批量删除回归
  13. 门户页退出登录
  14. `finally` 中清理测试评论、收藏、活动、动态、公告、分类，并显式校验测试评论标记已清空

## 2. 依赖安装

在前端目录执行：

```bash
cd Frontend
npm i
npx playwright install chromium
```

## 3. 运行方式

### 3.1 默认运行

```bash
cd Frontend
node scripts/smoke-flow.mjs
```

默认参数：
- `BASE_URL=http://127.0.0.1:5173`
- `API_BASE_URL=http://127.0.0.1:8080`
- `SMOKE_USERNAME=volunteer`
- `SMOKE_PASSWORD=123456`
- `SMOKE_ADMIN_USERNAME=admin`
- `SMOKE_ADMIN_PASSWORD=123456`
- `SMOKE_TEST_DATA_MARKER=smoke:<timestamp>`（可选；默认自动生成）

### 3.2 自定义环境变量

```powershell
cd Frontend
$env:BASE_URL='http://127.0.0.1:5173'
$env:API_BASE_URL='http://127.0.0.1:8080'
$env:SMOKE_USERNAME='volunteer'
$env:SMOKE_PASSWORD='123456'
$env:SMOKE_ADMIN_USERNAME='admin'
$env:SMOKE_ADMIN_PASSWORD='123456'
$env:SMOKE_TEST_DATA_MARKER='smoke:manual-check'
node scripts/smoke-flow.mjs
```

## 5. 关键实现说明

- 继续沿用现有 `Playwright + Node` 单脚本入口，不引入新的前端测试框架。
- 脚本会预置两类临时活动：
  - 主活动：用于报名、审核、签到签退、周统计和活动归档恢复链路
  - 收藏快照活动：用于验证收藏后即使活动当前信息被修改，收藏页仍展示快照字段
- 动态、公告和活动分类全部通过后端 API 临时创建，避免依赖固定种子数据。
- 活动、动态、公告的归档恢复均通过管理端 UI 操作完成，并用后端分页接口二次确认状态已落库。
- 连续 toast 读取增加“等待新提示文本”逻辑，避免将上一条提示误判为下一步结果。
- 脚本会把测试标记写入浏览器本地存储，由前端请求头 `X-Test-Data-Marker` 透传到评论创建接口，后端据此标记测试评论。
- 清理阶段除了删除带测试标记的评论，还会再次查询 `includeTestData=true` 的评论分页接口，明确确认没有残留测试评论。

## 6. 注意事项

- 运行前请确保前后端服务已启动：前端 `5173`，后端 `8080`。
- 默认账号为 `volunteer / 123456` 和 `admin / 123456`；如本地数据不同，请通过环境变量覆盖。
- 如果页面结构、按钮文案或关键交互调整，需要同步更新脚本选择器。
- 如果本地浏览器未安装，可先执行 `npx playwright install chromium`。
