# 自动化冒烟脚本说明（登录 / 报名 / 评论 / 退出）

更新时间：2026-03-12

## 1. 脚本位置

- 文件：`Frontend/scripts/smoke-flow.mjs`
- 覆盖流程：
  1. 志愿者登录
  2. 门户活动页报名
  3. 门户论坛发布评论
  4. 门户页退出登录

## 2. 依赖安装

在前端目录执行：

```bash
cd Frontend
npm i
npx playwright install chromium
```

## 3. 运行方式

### 3.1 默认运行

```bash
cd Frontend
node scripts/smoke-flow.mjs
```

默认参数：

- `BASE_URL=http://127.0.0.1:5173`
- `SMOKE_USERNAME=volunteer`
- `SMOKE_PASSWORD=123456`

### 3.2 自定义环境变量

```powershell
cd Frontend
$env:BASE_URL='http://127.0.0.1:5173'
$env:SMOKE_USERNAME='volunteer'
$env:SMOKE_PASSWORD='123456'
node scripts/smoke-flow.mjs
```

## 4. 成功输出示例

```text
登录：成功
报名：报名成功或已报名提示
评论：评论发布成功
退出：成功
```

## 5. 关键变更说明

- 评论内容已改为“社区服务体验反馈 + 时间戳”，不再写入“自动化冒烟评论”字样。
- 登录失败时会重新读取验证码并重试，避免一次验证码失败导致整条链路中断。

## 6. 注意事项

- 运行前请确保前后端服务已启动（前端 5173、后端 8080）。
- 如果页面文案或按钮文本调整，需要同步更新脚本选择器。
- 报名环节若返回“已报名”，属于可接受的幂等结果。
