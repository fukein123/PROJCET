# 平台完善记录

更新时间：2026-03-11

## 1. 当前完成状态

### 1.1 核心模块

- 鉴权与用户：已完成（登录、注册、JWT、个人资料、密码修改、用户管理）
- 活动管理：已完成（分类、活动、报名、审核、签到签退、打卡记录）
- 内容模块：已完成（动态、公告、论坛、评论、收藏、订单）
- 统计看板：已完成（管理员仪表盘 + 志愿者周统计）
- 定时任务：已完成（活动过期关闭 + 周统计定时生成）

### 1.2 前端模块

- 管理端：已完成主要业务页（活动、审核、内容、用户、设置、统计）
- 志愿者端：已完成活动中心、报名记录、打卡记录、我的帖子/评论/收藏、个人中心
- 门户端：已完成首页、活动、新闻、公告、论坛展示

## 2. 本次完善内容

### 2.1 业务闭环修复

- 新增“志愿者认证状态”管理能力：管理员可在用户管理中维护 `certified`。
- 修复帖子可见性：非管理员默认仅可见 `APPROVED` 帖子，防止待审数据泄露。
- 修复订单越权：非管理员创建兑换单时强制使用当前登录用户 ID。
- 增加用户名唯一性校验：资料更新与管理员编辑用户时均校验重名。

### 2.2 新增周统计能力

- 新增数据表：`volunteer_weekly_stats`。
- 新增接口：
  - `GET /api/dashboard/weekly-ranking`
  - `POST /api/dashboard/weekly-ranking/rebuild`
- 新增前端页面：管理员“志愿者周统计”页面。
- 定时任务落地：每周一 01:00 自动生成上周统计。

### 2.3 管理端功能补齐

- 内容管理页补齐动态/公告的新增与编辑。
- 志愿者“我的帖子”改为论坛分类下拉选择，减少手填分类 ID。

## 3. 验证记录

- 后端编译：`mvn -q -DskipTests compile` 通过。
- 前端构建：`npm.cmd run build` 通过。
