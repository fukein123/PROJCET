# 文档索引（file）

更新时间：2026-03-11

本项目的开发、接口、架构、部署与迭代文档统一维护在 `file/` 目录。

## 1. 文档分类

- 项目总览与迭代：
  - `01-开发文档.md`
  - `06-平台完善记录.md`
- 接口文档：
  - `02-接口文档.md`
  - `08-新增接口与数据结构说明.md`
- 架构与结构：
  - `03-结构和配置文档.md`
  - `04-系统设计文档.md`
  - `07-前后端分离结构说明.md`
- 部署运维：
  - `05-部署文档.md`
  - `nginx-cvs.conf`
  - `maven-settings.xml`
- 环境与技能记录：
  - `00-skills-安装记录.md`

## 2. 推荐阅读顺序

1. `01-开发文档.md`（看业务范围与完成目标）
2. `07-前后端分离结构说明.md`（看目录与分层边界）
3. `02-接口文档.md` + `08-新增接口与数据结构说明.md`（看接口）
4. `04-系统设计文档.md`（看规则与安全）
5. `05-部署文档.md`（看上线步骤）

## 3. 文档维护约定

- 新增功能必须同步更新接口文档与设计文档。
- 影响数据库结构的改动必须记录在 `08-新增接口与数据结构说明.md`。
- 迭代完成后，先更新 `06-平台完善记录.md` 再提交代码。
