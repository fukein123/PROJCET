# 本地审批工具说明

更新时间：2026-03-13

## 1. 当前审批链路

本项目当前唯一生效的审批链路是：

1. 助手编写或更新规格文档
2. 助手创建本地审批请求
3. 你在聊天中回复 `通过` 或 `需修改：...`
4. 助手把结果写入本地审批记录并决定是否进入下一阶段

## 2. 当前审批工具

- 审批脚本：`scripts/local-approval.ps1`
- 审批记录目录：`.approval-workflow/`
- 规格文档目录：`.spec-workflow/specs/`

这意味着：

- `spec` 文档仍按 `.spec-workflow` 组织
- 审批记录与状态改由 `.approval-workflow` 维护

## 3. 聊天审批动作

- 用户在聊天中回复 `通过`
- 用户在聊天中回复 `需修改：<具体意见>`

随后由助手执行本地脚本，把结果写入 `.approval-workflow/requests/`。

## 4. 支持的脚本命令

```powershell
pwsh .\scripts\local-approval.ps1 request -Title "<title>" -FilePath "<doc-path>" -Category spec -CategoryName "<name>"
pwsh .\scripts\local-approval.ps1 status -Id <approval-id>
pwsh .\scripts\local-approval.ps1 list
pwsh .\scripts\local-approval.ps1 approve -Id <approval-id> -Comment "用户聊天回复：通过"
pwsh .\scripts\local-approval.ps1 needs-revision -Id <approval-id> -Comment "用户聊天回复：需修改：..."
pwsh .\scripts\local-approval.ps1 delete -Id <approval-id>
```
