# 前后端分离结构说明

更新时间：2026-03-12

## 1. 根目录结构

```text
zero/
├─ admin/                      # 前端（Vue 3 + TS + Vite）
├─ backend/                    # 后端（Spring Boot + MyBatis-Plus）
├─ file/                       # 项目文档
├─ skills/                     # 本地技能库
├─ README.md
└─ .gitignore
```

## 2. 前端分层（`admin/src`）

- `api/`：接口封装，按业务域拆分。
- `views/`：页面层，按角色与模块拆分。
- `components/`：可复用组件。
- `stores/`：状态管理（Pinia）。
- `router/`：路由与权限守卫。
- `utils/`：请求、鉴权、校验等工具。
- `composables/`：复用逻辑（含门户登录守卫与跳转）。

## 3. 后端分层（`backend/src/main/java/com/community`）

- `common/`：配置、异常、工具、统一响应。
- `modules/auth`：登录注册。
- `modules/user`：用户与资料管理。
- `modules/activity`：活动、报名、审核、打卡。
- `modules/content`：动态、公告、论坛、评论、收藏、订单。
- `modules/dashboard`：统计看板与周榜。
- `modules/schedule`：定时任务。

## 4. 前后端边界约定

- 前端仅通过 `api/*` 调用后端 REST，不直接操作数据库。
- 后端 Controller 处理参数与权限，业务逻辑放在 Service。
- 统一响应使用 `ApiResponse`，分页统一 `PageResult`。
