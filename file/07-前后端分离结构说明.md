# 前后端分离结构说明

更新时间：2026-03-11

## 1. 根目录结构

```text
zero/
├─ admin/                      # 前端（Vue 3 + TS + Vite）
├─ backend/                    # 后端（Spring Boot + MyBatis-Plus）
├─ file/                       # 项目文档
├─ skills/                     # 项目内辅助 skills
├─ README.md
└─ .gitignore
```

## 2. 前端分层（`admin/src`）

- `api/`：接口封装，按业务域拆分（`auth.ts`、`activity.ts`、`content.ts`、`dashboard.ts`、`user.ts`）
- `views/`：页面层，按角色与模块拆分（`portal/`、`dashboard/`、`activity/`、`volunteer/` 等）
- `components/`：可复用组件（表单搜索、表格等）
- `stores/`：状态管理（Pinia）
- `router/`：路由与权限入口
- `utils/`：请求封装、鉴权工具、校验工具
- `layouts/`：主布局

## 3. 后端分层（`backend/src/main/java/com/community`）

- `common/`
  - `config/`：安全、跨域、OpenAPI、MyBatis 配置
  - `exception/`：业务异常与全局异常处理
  - `util/`：JWT 与安全上下文工具
  - `web/`：统一返回结构与分页结构
- `modules/`
  - `auth/`：登录注册
  - `user/`：用户与资料管理
  - `activity/`：活动、报名、审核、签到签退
  - `content/`：动态、公告、论坛、评论、收藏、订单
  - `dashboard/`：统计看板与周统计
  - `schedule/`：定时任务

## 4. 前后端边界约定

- 前端仅通过 `api/*` 调后端 REST 接口，不直连数据库。
- 后端 controller 仅处理入参与权限；业务逻辑放 service。
- service 不直接依赖前端参数对象；通过 DTO/实体转换处理。
- 所有接口统一走 `ApiResponse`，分页统一走 `PageResult`。

- 架构设计：`03`、`04`、`07`
