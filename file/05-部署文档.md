# 部署文档

更新时间：2026-03-14

## 1. 环境要求

- JDK 21
- Maven 3.9+
- Node.js 20+
- MySQL 8.0+
- Nginx（可选，用于反向代理）

## 2. 数据库准备

先创建数据库：

```bash
mysql -uroot -p123456 -e "CREATE DATABASE IF NOT EXISTS CVS DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

如果部署环境需要一次性创建账号与授权，可由 DBA 或运维手工执行：

```bash
mysql -uroot -p123456 < backend/src/main/resources/db/init-database.sql
```

注意：

- 运行期结构初始化由 Flyway 完成
- 不再使用 `schema.sql` / `data.sql` 直接灌库

## 3. 后端构建与启动

```bash
cd backend
mvn clean package -DskipTests
java -jar target/backend-2.0.0.jar --spring.profiles.active=prod
```

默认信息：

- 端口：`8080`
- Swagger：`http://localhost:8080/swagger-ui.html`

部署建议：

- 通过环境变量或外部配置覆盖数据库账号、密码、JWT 密钥
- 持久化 `uploads/` 目录，避免图片和证件文件因重启丢失

## 4. 前端构建与发布

```bash
cd Frontend
npm install
npm run build
```

构建产物目录：

- `Frontend/dist`

开发预览：

```bash
npm run preview
```

## 5. Nginx 反向代理

可参考：

- [nginx-cvs.conf](/f:/zero/file/nginx-cvs.conf)

核心思路：

- `/api/` 代理到后端 `8080`
- 前端静态资源由 Nginx 提供
- 上传目录如需对外访问，应使用受控路径，不直接暴露敏感证件文件原始目录

## 6. 上线前检查清单

- 确认 Flyway 迁移在目标库可正常执行
- 确认管理员与志愿者登录后路由边界正确
- 确认门户公开页、详情页、商城兑换链路可用
- 确认审计日志、认证审核、订单状态流转已联通
- 确认 UTF-8 编码正常，无乱码页面或乱码文档
