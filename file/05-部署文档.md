# 部署文档

## 1. 环境要求

- JDK 21
- Maven 3.9+
- Node.js 20+
- MySQL 8.0+
- Nginx

## 2. 数据库初始化

```bash
mysql -uroot -p123456 -e "CREATE DATABASE IF NOT EXISTS CVS DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -uroot -p123456 CVS < backend/src/main/resources/db/schema.sql
mysql -uroot -p123456 CVS < backend/src/main/resources/db/data.sql
```

## 3. Maven 设置

建议在 `%USERPROFILE%\\.m2\\settings.xml` 中声明本地仓库：

```xml
<settings>
  <localRepository>E:/mvn_repo</localRepository>
</settings>
```

Maven 安装目录使用 `E:\MAVEN`。

## 4. 后端打包与运行

```bash
cd backend
mvn clean package -DskipTests
java -jar target/backend-1.0.0.jar --spring.profiles.active=prod
```

默认端口：`8080`

## 5. 前端打包

```bash
cd admin
npm install
npm run build
```

产物目录：`admin/dist`

## 6. Nginx 反向代理（端口 70）

参考配置：`file/nginx-cvs.conf`

核心思路：

- `70` 端口对外服务前端静态资源
- `/api` 代理到后端 `http://127.0.0.1:8080`
