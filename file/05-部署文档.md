# 部署文档

更新时间：2026-03-12

## 1. 环境要求

- JDK 21
- Maven 3.9+
- Node.js 20+
- MySQL 8.0+
- Nginx

## 2. 数据库初始化

```bash
mysql -uroot -p123456 -e "CREATE DATABASE IF NOT EXISTS CVS DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -uroot -p123456 CVS < backend/src/main/resources/db/schema.sql
mysql -uroot -p123456 CVS < backend/src/main/resources/db/data.sql
```

## 3. 后端构建与运行

```bash
cd backend
mvn clean package -DskipTests
java -jar target/backend-2.0.0.jar --spring.profiles.active=prod
```

- 默认端口：`8080`
- OpenAPI：`http://localhost:8080/swagger-ui.html`

## 4. 前端构建与运行

```bash
cd Frontend
npm install
npm run build
npm run dev
```

- 构建产物：`Frontend/dist`
- 开发端口：`5173`

## 5. Nginx 反向代理

参考同目录配置文件：`file/nginx-cvs.conf`

核心思路：

- `/api/` 代理到后端 `8080`
- 静态资源与前端页面由 Nginx 提供

## 6. 生产建议

- 使用独立数据库账号，避免直接使用 `root`
- JWT 密钥和数据库密码放入环境变量
- 对外服务启用 HTTPS
- 配置日志轮转与健康检查
