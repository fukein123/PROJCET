# 开发文档

更新时间：2026-03-12

## 1. 项目目标

构建一个前后端分离的社区志愿服务管理系统，覆盖三类使用场景：

- 管理端：活动管理、报名审核、内容管理、用户管理、统计看板。
- 志愿者端：注册登录、活动报名、签到签退、论坛互动、个人中心。
- 门户端：活动浏览、资讯公告、论坛讨论（报名与评论需要登录）。

## 2. 技术栈

### 2.1 后端（`backend`）

- Java 21
- Spring Boot 3.5.11
- Spring Security + JWT
- MyBatis-Plus 3.5.16
- SpringDoc OpenAPI 2.8.16
- Maven 3.9.13

### 2.2 前端（`admin`）

- Vue 3 + TypeScript + Vite
- Element Plus
- Pinia + Vue Router
- Axios + Day.js + ECharts

## 3. 当前完成能力

### 3.1 账号与权限

- 登录、注册、JWT 鉴权。
- RBAC 角色控制：`ADMIN` / `VOLUNTEER`。
- 登录入口区分管理员与用户，并由后端强校验角色匹配。

### 3.2 活动流程

- 活动分类与活动管理（管理员）。
- 活动报名、审核、签到签退、打卡记录（志愿者/管理员）。
- 门户活动报名前必须登录。

### 3.3 内容系统

- 动态与公告发布、编辑。
- 论坛帖子发布、审核。
- 评论新增与列表展示。
- 门户论坛支持评论展示和登录后评论。

### 3.4 统计与定时任务

- 管理端仪表盘。
- 周统计榜单（查询 + 重建）。
- 定时任务：活动过期处理、周统计生成。
