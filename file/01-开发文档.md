# 开发文档

## 1. 项目目标

构建一个前后端分离的社区志愿服务管理系统，覆盖：

- 管理员端：活动、分类、报名审核、新闻公告、论坛审核、用户管理、仪表盘统计
- 志愿者端：注册登录、活动查询与报名、签到签退、帖子发布、评论、收藏、个人中心
- 门户端：首页、志愿活动、社区新闻、社区公告、社区论坛

## 2. 技术栈

### 后端（`backend`）

- Java 21
- Spring Boot 3.5.11
- MyBatis-Plus 3.5.16
- JWT（jjwt 0.13.0）
- Spring Security
- SpringDoc OpenAPI 2.8.16（Boot3 兼容最新）
- Hutool 5.8.43
- Lombok 1.18.44
- Hibernate Validator（starter-validation）
- Maven 3.9.13
- `@Scheduled` 定时任务

### 前端（`admin`）

- Vue 3 + TypeScript
- Element Plus
- Axios
- Pinia
- Vue Router
- Lodash-es
- Day.js
- ECharts
- Vite

## 3. 开发模式

- 前后端完全分离
- 后端 RESTful API
- 前端通过 Axios 调用 API
- JWT 无状态认证
- RBAC 角色权限（`ADMIN` / `VOLUNTEER`）

## 4. 已完成功能

### 4.1 鉴权与用户

- 登录（管理员/志愿者角色校验）
- 志愿者注册
- JWT 签发与校验
- 用户资料查询/更新
- 密码修改
- 管理员分页查询与编辑用户
- 管理员可维护志愿者认证状态（`certified`）

### 4.2 活动管理

- 活动分类 CRUD（管理员）
- 志愿活动 CRUD（管理员）
- 活动分页查询（多条件）
- 志愿者活动报名
- 管理员审核报名（通过/拒绝+拒绝原因）

### 4.3 打卡逻辑

- 志愿者签到：仅允许 `开始前15分钟~开始时间`
- 志愿者签退：仅允许 `结束前15分钟之后`
- GPS 距离校验（Haversine，500m 阈值）
- 打卡记录查询

### 4.4 内容模块

- 信息动态分页
- 公告分页
- 论坛帖子分页、我的帖子发帖/改帖（改后自动待审核）
- 帖子审核（管理员）
- 评论查询/新增
- 轮播图查询
- 收藏增删查
- 兑换订单分页/新增

### 4.5 仪表盘

- 统计卡片：
  - 志愿活动数量
  - 社区帖子数量
  - 兑换订单数量
  - 志愿者数量
- 图表：
  - 近一周报名折线图
  - 活动类型柱状图
  - 帖子类型饼图
- 志愿者周统计：
  - 周服务时长与完成场次排名
  - 支持按周查询与管理员手动重建

### 4.6 定时任务

- 每日 00:00 自动结束已过期活动
- 每周一 01:00 自动生成上周志愿者周统计
