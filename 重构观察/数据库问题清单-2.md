## 建议添加的索引

```sql
-- activity
CREATE INDEX idx_activity_creator ON activity (creator_id);
CREATE INDEX idx_activity_status ON activity (status, create_time);

-- activity_application
CREATE INDEX idx_activity_application_user ON activity_application (user_id, create_time);

-- activity_check_record
CREATE INDEX idx_activity_check_record_user ON activity_check_record (user_id);

-- forum_post
CREATE INDEX idx_forum_post_user ON forum_post (user_id, create_time);

-- comment_info
CREATE INDEX idx_comment_info_user ON comment_info (user_id, create_time);

-- exchange_order
CREATE INDEX idx_exchange_order_status_time ON exchange_order (status, create_time);
```

## 建议添加的 CHECK 约束

```sql
ALTER TABLE activity ADD CONSTRAINT chk_activity_target_count CHECK (target_count > 0);
ALTER TABLE activity ADD CONSTRAINT chk_activity_point_reward CHECK (point_reward >= 0);
ALTER TABLE mall_product ADD CONSTRAINT chk_mall_product_stock CHECK (stock >= 0);
ALTER TABLE sys_user ADD CONSTRAINT chk_sys_user_points CHECK (points >= 0);
```
