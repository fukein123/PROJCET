# Skills（开发辅助）

本目录用于存放开发过程中可被工具/智能体加载的 skills（规范、工作流、排错等）。

已准备：

- `frontend-design/`：来自 `anthropics/skills` 的前端设计 skill（必须）
- `remotion/`：来自 `remotion-dev/skills` 的 Remotion skill（必须）
- `ui-ux-pro-max/`：来自 `nextlevelbuilder/ui-ux-pro-max-skill` 的 UI/UX 指南（必须）
- `pdf/`：来自 `anthropics/skills` 的 PDF skill

仓库缓存（避免重复下载）：

- `skills/_repos/`：clone 的上游仓库

说明：

- 若后续还需要补充（如 Systematic Debugging / Error Log Summarizer 等），可以继续将上游仓库拉到 `skills/_repos/` 并复制对应 `SKILL.md` 到 `skills/<skill-name>/`。
